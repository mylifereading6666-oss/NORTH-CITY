# NORTH CITY

北海道・札幌の街を、実際の地理データに沿って探索するスマートフォン対応3Dオープンワールドゲームの試作プロジェクトです。

## 現在の試作版
- Three.jsによるブラウザ3D表示
- タッチ操作：左パッドで移動、画面右側のドラッグで視点変更
- 歩行・走行・ジャンプ・三人称カメラ
- OpenStreetMapから札幌中心部の道路・建物形状を取得
- 国土地理院の標高タイル（DEM5A）を使った地形メッシュ生成
- 標高タイルが取得できない場合も、平面マップで起動を継続
- スマートフォンの負荷を抑えるため描画解像度に上限を設定

## 起動
GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で公開元を設定します。ES Modulesを使用しているため、ローカルではHTTPサーバー経由で開いてください。

## 地理データとクレジット
- 地図の道路・建物形状：© OpenStreetMap contributors — https://www.openstreetmap.org/copyright
- 標高データ：国土地理院 — https://maps.gsi.go.jp/development/ichiran.html

OpenStreetMapのデータはODbLで提供されています。公開時は出典表示とライセンス条件を維持してください。国土地理院のデータについても、利用するデータ・タイルの利用条件と出典表示を確認してください。

## 現在の制限と次の開発段階
この段階は地図表示・操作確認用の試作版です。標高メッシュは取得できたタイルを使って生成しますが、道路・建物の地面への正確な追従、建物高さの完全な実測反映、地形の細部、現実の天候・季節との同期は今後の改善項目です。建物高さに地図データがない場合は仮の高さを使用します。

今後は札幌駅周辺の精度を確認しながら、大通公園・すすきの・狸小路へマップ範囲を拡張します。
